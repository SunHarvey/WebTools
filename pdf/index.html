    Combine PDF files privately in your browser

    This PDF merger combines the pages from multiple PDF files into one downloadable document. It runs in your browser using a locally hosted PDF library, including the page-copying and document-writing operations needed to create a real PDF. Your PDF files are not uploaded. They are read into temporary browser memory and passed to a same-origin browser worker for processing; file bytes are never sent to UtilCover, a third-party API, or a CDN. The page does not save document contents in local or session storage or recent-tool history. Temporary selections and output are cleared when you leave the page or return through browser history.

    How to merge PDF files

    1. Select at least two PDF files.Choose the files from your device. The merger accepts up to 20 files, checks their PDF headers locally, and rejects files outside the published size limits before starting the merge.
    2. Set the page order.Use the Move up and Move down controls to choose the document order. The final PDF follows this list from top to bottom. Remove a file to exclude it before merging.
    3. Merge and download.Select Merge PDFs, wait for the local worker to finish, then download the result as merged.pdf. Review the output in a trusted PDF viewer. Use Clear or navigate away to erase the temporary list and download state from this page.

    Examples and expected behavior

    Join statements in a chosen order

    Add January, February, and March statements, then arrange them chronologically. The merger copies each source PDF's pages in that selected order; it does not infer dates from filenames or inspect document text.

    Combine documents with different page sizes

    Letter, A4, and landscape pages can be combined. Each copied page keeps its own page dimensions; the tool does not resize pages to a common paper size or render the documents as images.

    Check the output before sharing

    The output is a newly written PDF. Rewriting changes the document structure, so existing digital signatures cannot remain valid. Interactive forms, bookmarks, attachments, document metadata, or other document-level features may not be preserved by a page merge.

    Supported files, limitations and resource limits

    The tool merges page content from ordinary readable PDFs in the displayed order. It does not split, compress, convert, repair, OCR, redact, sign, or validate PDF documents. Password-protected PDFs are not supported. The merger does not ask for or retain PDF passwords. If a file is damaged, unsupported, or protected, the tool clears any stale output and shows a generic error without displaying the file contents or parser diagnostics.

    This is a page merger, not a document-feature preservation tool. Digital signatures are invalidated when the PDF is rewritten. Interactive form fields, bookmarks, attachments, embedded scripts, tagged accessibility structure, and some metadata may be lost or changed. Review the merged result and retain the original files. The tool does not guarantee conformance to PDF/A, PDF/UA, or any other archival or accessibility standard.

    Limits are enforced in the browser: at most 20 files, 25 MiB per file, 40 MiB combined input, 500 pages across all files, and 60 MiB output. The merge operation is stopped after 45 seconds. These caps bound typical browser work but cannot guarantee that every device handles a complex PDF equally quickly. Choose smaller files if a merge times out or reaches a limit.

    The PDF library is bundled with this site and loaded locally only when you start a merge; it is not fetched from a third-party CDN. The worker receives file bytes through browser messaging, not an HTTP request. The page makes no file-upload request, does not create an account, and does not persist your files or generated PDF. Browser extensions, device backups, and downloads are outside the page's control.

    PDF merger FAQ

    Are my PDF files uploaded?

    No. File reading and merging happen in the browser and its same-origin worker. The file data is not sent to a server, third-party API, or CDN, and the page does not store it in browser storage or recent-tool history.

    Can I merge password-protected PDFs?

    No. The tool does not ask for a PDF password. Protected files return a generic local error; the password or document content is never transmitted.

    Will signatures, forms, and bookmarks remain intact?

    Do not rely on that. The merger writes a new PDF; existing digital signatures are invalidated, and interactive forms, bookmarks, attachments, or metadata may not be preserved.

    Can I compress or split a PDF here?

    No. This page only combines pages from multiple PDFs. It does not provide compression, splitting, conversion, repair, OCR, or validation.

    What are the file and page limits?

    You can select up to 20 PDFs, with a maximum of 25 MiB per file, 40 MiB combined input, 500 total pages, and 60 MiB output. Processing is stopped after 45 seconds to protect the browser tab.
