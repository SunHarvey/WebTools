Supported files and limits

This tool accepts one readable, unencrypted PDF up to 25 MiB and 500 pages. Page selection supports up to 20 non-overlapping ranges. The output is limited to 60 MiB and processing stops after 45 seconds. Deleting every page is not allowed.

Page numbers refer to the original PDF. Rotations add to each selected page’s existing orientation. When pages are deleted, the remaining pages keep their original order and receive new page numbers in the downloaded file. Separate ranges with commas; overlapping page selections are rejected.

Rewriting a PDF can invalidate digital signatures. This tool does not guarantee preservation of interactive forms, bookmarks, attachments, or document metadata. Review the edited file and keep the original.

File reading and page editing run locally in browser memory and a same-origin worker. The document is not sent to a server, third-party API, or CDN, and is not saved in browser storage or recent-tool history. Temporary file selection and download links are cleared when leaving the page or restoring it through browser history.

PDF page editor FAQ

Are my PDFs uploaded?

No. File reading and page editing happen locally in this browser and its same-origin worker. PDF data is not sent to a server, third-party API, or CDN.

Can I rotate only some pages?

Yes. Enter individual page numbers and ranges, for example 2, 5-7, then choose a rotation. Use all to select every page.

Can I delete every page?

No. At least one page must remain in the output PDF.

Will a digital signature remain valid?

No. Editing rewrites the PDF, which invalidates existing digital signatures. Keep the original if its signature matters.
