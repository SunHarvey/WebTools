    1. Select your images.Choose one or more JPG/JPEG or PNG files from your device. The tool checks file size and image dimensions locally before embedding them.

    What to expect

    Combine scanned pages

    Mix portrait and landscape images

    Each image gets an A4 page whose orientation follows its pixel dimensions. The image is scaled proportionally inside a small white margin; it is not cropped or stretched.

    Keep the original images

    Supported formats and limits

    Only ordinary JPEG/JPG and PNG images are supported. SVG, WebP, GIF, HEIC/HEIF, animated images, and password-protected or existing PDF files are not accepted. JPEG and PNG image data is embedded in the generated PDF; no OCR, image editing, or PDF compression is performed.

    Limits are enforced locally: up to 20 images, 16 MiB per image, 40 MiB total input, 12 megapixels per image, 40 megapixels total, 60 MiB output, and 45 seconds per conversion. Large or malformed files are rejected with a generic message; file contents and parser diagnostics are not displayed.

    Pages use A4 dimensions and a 36-point white margin. Each image is fitted proportionally to the page, without cropping. Digital photos that rely on EXIF orientation metadata may not retain that orientation in the PDF; check the result before relying on it. The PDF is a new document and does not carry the original image files' metadata.

    Files are temporarily read into browser memory and passed as bytes to a same-origin worker. They are not uploaded, placed in local or session storage, or saved to recent-tool history. Temporary selections and the download link are cleared when leaving the page or returning through browser history.

    Image to PDF FAQ

    Are my images uploaded?

    No. Image reading and PDF creation run locally in your browser and its same-origin worker. Image bytes are not sent to a server, third-party API, or CDN, and are not saved in browser storage or recent-tool history.

    Can I combine JPG and PNG images?

    Yes. You can select both formats in one batch. Each image becomes one PDF page in the order shown in the list.

    Can I choose paper size or crop an image?

    This version uses A4 pages, switches automatically between portrait and landscape based on image dimensions, and fits the full image without cropping. Custom paper sizes, margins, and cropping are not supported.

    Does this tool reduce image file size?

    No. It embeds image data to create PDF pages; it is not an image compressor. The generated PDF has a 60 MiB output limit.
