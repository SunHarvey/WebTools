    在浏览器本地私密地将图片转换为 PDF

    这个图片转 PDF 工具会将每张 JPG 或 PNG 图片放到单独的 A4 页面中。调整图片顺序后，即可生成并下载一个 PDF。PDF 库与转换 Worker 由本站提供；图片字节只在本地处理，不会发送到服务器、第三方 API 或 CDN。

    如何将 JPG 或 PNG 转换为 PDF

    1. 选择图片。从设备中选择一张或多张 JPG/JPEG 或 PNG 图片。工具会在本地检查文件大小与图片尺寸。
    2. 调整页面顺序。使用“上移”和“下移”控制图片在 PDF 中出现的顺序，也可以移除不需要的图片。
    3. 生成并下载 PDF。点击“生成 PDF”，处理完成后下载 images.pdf。每页使用 A4 纸张；横向图片使用横向页面，图片居中并按比例完整适配。

    转换效果说明

    合并扫描页面

    按顺序选择扫描件，即可生成多页 PDF。页面顺序由列表决定，不会根据文件名或时间自动排序。

    混合纵向和横向图片

    每张图片使用一张 A4 页面，并根据图片像素宽高自动选择纸张方向。图片会保留比例、完整放入页面并留出白边，不会裁剪或拉伸。

    保留原始图片

    工具会创建单独的 PDF，不会修改源图片。分享或归档前请检查下载的文档。

    支持格式与资源限制

    仅支持常规 JPEG/JPG 和 PNG 图片。不支持 SVG、WebP、GIF、HEIC/HEIF、动图或已有 PDF 文件。工具会把图片数据嵌入生成的 PDF，不提供 OCR、图片编辑或 PDF 压缩。

    所有限制均在本地执行：最多 20 张图片、每张 16 MiB、输入总计 40 MiB、每张 1200 万像素、总计 4000 万像素、输出 60 MiB、单次处理 45 秒。超过限制或格式错误的文件会显示通用提示，不会展示文件内容或解析器诊断信息。

    页面尺寸为 A4，并留有 36 点白边。图片按比例完整适配，不会裁剪。依赖 EXIF 方向信息的数码照片在 PDF 中可能无法保留该方向；请检查转换结果。本工具会创建新的 PDF，不会复制原图片的元数据。

    文件会临时读入浏览器内存，并以字节形式发送给同源 Worker。文件不会上传、写入 localStorage 或 sessionStorage，也不会加入最近使用记录。离开页面或通过浏览器历史返回时，临时文件列表和下载链接都会清除。

    图片转 PDF 常见问题

    图片会上传吗？

    不会。图片读取与 PDF 创建都在浏览器及同源 Worker 中完成。图片字节不会发送到服务器、第三方 API 或 CDN，也不会保存到浏览器存储或最近使用记录。

    可以在同一份 PDF 中混合 JPG 和 PNG 吗？

    可以。可在同一批次中同时选择两种格式；每张图片按照列表顺序生成一个 PDF 页面。

    可以自选纸张尺寸或裁剪图片吗？

    当前版本使用 A4 页面，并根据图片尺寸自动选择纵向或横向；图片会按比例完整适配，不会裁剪。暂不支持自定义纸张尺寸、边距或裁剪。

    这个工具会压缩图片吗？

    不会。它会把图片嵌入 PDF 页面，不是图片压缩工具。生成的 PDF 输出上限为 60 MiB。
