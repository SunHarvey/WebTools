网页计算器

支持鼠标和键盘操作的快速日常算术计算。

0
键盘快捷键：数字键、+、-、*、/、Enter、Backspace、Esc

用页面按键或键盘完成基础算术

这款紧凑计算器处理日常的加法、减法、乘法和除法，既适合一步运算，也适合连续输入。它模拟简易口袋计算器：选中下一个运算符时，会先算出正在等待的那一步。做合计和连续调整很直接，但它并不是可以输入完整公式、再按优先级解析的表达式工具。

三步开始计算

  1. 输入第一个操作数点击数字按键或使用键盘数字。需要小数时输入一个小数点，也可以在输入前后用 ± 切换正负号。
  2. 选择运算并继续选择 +、−、× 或 ÷，再输入下一个操作数。继续选择运算符会立即完成上一项；若尚未开始第二个数，连续选择会替换等待中的运算符。
  3. 得到结果或修正输入按 = 或 Enter 结束计算。Backspace 删除最后一个输入字符，Escape、Delete 或 C 会清空当前状态并开始新的计算。

日常使用示例

逐项累加小额数字

依次输入 18.50 + 7.25 + 4.00，再按等号即可合计三项金额。每次选择新的加号时，前两个数会先得到结果，并成为下一步的第一个操作数。无需分组或特殊函数的流水合计很适合这种方式。

理解连续运算顺序

连续即时执行不采用运算符优先级。输入 2 + 3 × 4 在这里得到 20，不是按优先级得到的 14：选择 × 时会先把 2 + 3 算成 5，之后再用 5 乘以 4。

不清空就修正数字

本来要输入 129，却输入了 128，可以按 Backspace 删除 8，再补上 9。如果第二个操作数尚未开始，而之前选错了运算符，直接按正确运算符即可触发替换运算符，不会提前计算。

输入负的第二个数

选择运算符后，可以先用正负号切换让下一项从负数开始，再输入具体数字。这样能够用按键顺序完成 10 +（−3），尽管页面本身没有解析括号表达式的能力。

执行方式与限制

  • 计算器只处理四种基础二元运算，采用连续即时执行，不采用运算符优先级，也不能把一整条表达式作为文本输入。正负号切换修改当前操作数，替换运算符则修改等待中的运算。
  • 每个操作数最多输入 12 位数字；负号和小数点不计入数字位数。达到上限后，继续按数字键不会添加更多字符。
  • 结果按 12 位有效数字格式化。如果普通字符串会过长，显示会改用科学记数法并缩短尾数。底层仍是 JavaScript 浮点运算，因此可能出现舍入影响。
  • 除以零以及任何非有限结果都会进入错误状态。出错后输入数字或执行清除即可重新开始；页面不会把无穷大当作普通结果显示。
  • 本工具不提供 %、括号、科学函数、存储器、历史记录或任意精度。页面刷新或再次访问时不会保留数值，当前显示框就是唯一结果。

常见问题

为什么连续计算与书面公式结果不同？

每当选择下一个运算符，引擎都会先计算当前等待的一对数值，不会先把乘除排在加减之前。如果公式需要另一种分组方式，应把它拆成多个独立步骤，并手动使用中间结果。

键盘支持哪些按键？

可使用数字、小数点、+、-、*、/、Enter 或 =、Backspace、Escape、Delete 和 C。键盘以星号表示乘法、斜线表示除法，而页面按钮显示的是 × 和 ÷。

较长的结果怎样显示？

格式化过程保留 12 位有效数字。普通写法足够短时直接显示，字符过长时则采用科学记数法。这只是 JavaScript Number 的显示整理，并不代表每一位十进制数字都精确保存。

连续按两个运算符会怎样？

如果还没有开始输入第二个操作数，后按的运算符会替换前一个。例如按 8、+、÷ 后，准备执行的是 8 除以下一个数；如果第二个数已经输入，再选运算符就会先完成当前运算。
