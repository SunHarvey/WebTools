    在浏览器中私密地合并 PDF 文件

    这个 PDF 合并工具会将多个 PDF 中的页面合并为一个可下载的文档。文件不会上传，处理会在浏览器本地进行。它使用随本站静态资源一起提供的 PDF 库，在浏览器本地读取文件，并通过同源浏览器 Worker 完成页面复制和 PDF 写入。文件字节不会发送给 UtilCover、第三方 API 或 CDN。本页面不会把文档内容写入 localStorage、sessionStorage 或最近使用记录。离开页面或通过浏览器历史返回时，临时文件列表和下载结果都会清除。

    如何合并 PDF 文件

    1. 选择至少两个 PDF 文件。从设备中选取文件。工具最多接收 20 个文件，会在本地检查 PDF 文件头，并在开始合并前检查文件大小限制。
    2. 设置页面顺序。使用“上移”和“下移”按钮调整顺序。最终 PDF 会按照你设置的所选顺序，从列表顶部到底部依次排列。合并前也可以移除不需要的文件。
    3. 合并并下载。点击“合并 PDF”，等待本地 Worker 完成后，下载名为 merged.pdf 的结果。建议使用可信的 PDF 阅读器检查文件。点击“清除”或离开页面，会清除页面中的临时列表和下载状态。

    使用示例与预期结果

    按指定顺序合并账单

    添加一月、二月和三月的账单，然后按月份调整顺序。工具按照列表顺序复制各文件页面，不会从文件名推断日期，也不会读取文档文本。

    合并不同纸张尺寸的页面

    Letter、A4 和横向页面可以放在同一个文件中。每页保留各自的页面尺寸；工具不会把全部页面缩放为同一种纸张，也不会把 PDF 页面栅格化成图片。

    分享前检查输出文件

    合并会创建新的 PDF 并重写文档结构，因此已有数字签名不再有效。交互式表单、书签、附件、文档元数据及其他文档级功能可能不会保留。

    文件支持、功能边界与资源限制

    本工具按照页面列表顺序合并可读取 PDF 的页面内容。它不提供压缩、格式转换、修复、OCR、脱敏、签名或 PDF 有效性验证。暂不支持密码保护的 PDF；工具不会询问或保存 PDF 密码。如果文件损坏、格式不受支持或受到密码保护，页面会清除旧结果并显示通用错误，不会展示文件内容或底层解析器诊断信息。

    这是页面合并工具，不保证保留 PDF 的全部文档功能。重写会使原有数字签名失效；交互式表单字段、书签、附件、嵌入脚本、无障碍标签结构和部分元数据可能丢失或改变。请检查合并结果并保留原始文件。工具不会认证 PDF/A、PDF/UA 或其他归档及无障碍标准。

    所有限制都在浏览器本地执行：最多 20 个文件、每个文件 25 MiB、输入总大小 40 MiB、合并总页数 500 页、输出 60 MiB。合并处理会在 45 秒后停止。这些限制用于约束常见设备上的浏览器工作量，但不保证每台设备都能同样快速地处理复杂 PDF。遇到超时或达到上限时，请改用更小的文件。

    PDF 库随本站本地打包，仅在你开始合并时加载，不会从第三方 CDN 获取。Worker 通过浏览器内部消息接收文件数据，不会发起文件上传请求。无需账户，文件与合并结果也不会持久保存。浏览器扩展、设备备份和下载文件不受此页面控制。

    PDF 合并常见问题

    PDF 文件会上传吗？

    不会。文件读取和合并都在浏览器及其同源 Worker 中完成。文件数据不会发送到服务器、第三方 API 或 CDN，也不会写入浏览器存储或最近使用记录。

    可以合并带密码的 PDF 吗？

    不可以。工具不会询问 PDF 密码。受保护文件只会返回通用本地错误，密码和文档内容都不会传输。

    数字签名、表单和书签会保留吗？

    请勿依赖它们会保留。合并会写入新的 PDF，原有数字签名会失效；交互式表单、书签、附件或元数据也可能无法保留。

    可以压缩或拆分 PDF 吗？

    本页面不提供 PDF 压缩。要按页码范围提取并生成多个 PDF，请使用PDF 拆分与页面提取工具。

    文件和页数上限是多少？

    最多选择 20 个 PDF；每个文件最大 25 MiB，输入总大小最多 40 MiB，合并总页数最多 500 页，输出最多 60 MiB。为保护浏览器标签页，处理会在 45 秒后停止。
