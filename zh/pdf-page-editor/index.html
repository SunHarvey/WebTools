如何编辑 PDF 页面

  1. 选择一个 PDF。文件将在本地读取。暂不支持受密码保护或超出页面/大小限制的文档。
  2. 选择页面和操作。输入 all 或页码范围，例如 1-3, 5。选择旋转或删除；输出至少保留一页。
  3. 应用并下载。点击“应用并生成 PDF”，即可下载名为 edited.pdf 的新文件。原文件不会被修改。

删除不需要的页面

输入 1, 8-10 并选择“删除所选页面”。剩余页面保持原有顺序。

支持的文件和限制

支持单个可读取、未加密且不超过 25 MiB、500 页的 PDF。页码范围最多 20 组，不能重叠；输出最大 60 MiB，处理超过 45 秒会停止。不能删除全部页面。

页码以原始 PDF 为准。旋转角度会在每页当前方向上累加。删除页面后，其余页面仍保持原有顺序，并在下载的新文件中重新编号。多个范围请用逗号分隔；相交的页面范围会被拒绝。

重新写入 PDF 可能导致数字签名失效。本工具不保证保留交互式表单、书签、附件或文档元数据。请检查修改后的文件并保留原件。

文件读取和页面编辑均在浏览器内存及同源 Worker 中进行。文档不会发送到服务器、第三方 API 或 CDN，也不会保存到浏览器存储或最近使用工具列表。离开页面或通过浏览器历史返回时，会清除临时文件选择和下载链接。

PDF 页面编辑器常见问题

PDF 会上传吗？

不会。文件读取和页面编辑在当前浏览器及同源 Worker 中完成，PDF 数据不会发送到服务器、第三方 API 或 CDN。

可以只旋转部分页面吗？

可以。输入页码或范围，例如 2, 5-7，再选择旋转方式。输入 all 可选择全部页面。

可以删除所有页面吗？

不可以，输出 PDF 至少要保留一页。

数字签名会保持有效吗？

不会。编辑操作会重新写入 PDF，因此已有数字签名会失效。如果签名有效性很重要，请保留原文件。
