在本地转换 CSV、TSV 与 JSON

本工具会按 CSV 引号规则解析字段，不会简单地按逗号或换行拆分文本。你可以明确选择逗号或制表符，选择是否使用表头，并在 CSV 与 JSON 之间双向转换。CSV 单元格始终作为字符串，不猜测数字、布尔值或日期；JSON 数字以原始文本写出，避免 JavaScript 浮点数舍入改变大整数。输入、输出和结构均有限制，页面不会上传或保存你的数据。

如何使用 CSV / TSV 转换器

  1. 选择转换方向和分隔符。选择 CSV / TSV 转 JSON，或 JSON 转 CSV / TSV，然后明确选择逗号或制表符。工具不会自动猜测分隔符。解析 CSV 时，还可以选择第一条记录是否包含表头。
  2. 粘贴一张表格或一个 JSON 数组。在输入框中粘贴普通文本。带引号的 CSV 字段可以包含逗号、制表符、双引号转义和字段内换行。启用表头后，每条 CSV 记录的字段数量必须一致。
  3. 转换、检查并复制。开始转换后，请先检查结果再复制。错误消息会按页面语言显示，不会回显你的输入。点击清除或离开页面，临时数据会从页面内存中清理。

CSV 与 JSON 转换示例

保留前导零和看似布尔值的文本

输入表头 code,active 和数据 007,true，CSV 转 JSON 会得到 {"code":"007","active":"true"}。每个 CSV 单元格始终是字符串，不会把编号、布尔值、日期或类似空值的内容自动转换类型，避免表格中的文本被改写。

解析带逗号和换行的引用字段

字段 "said ""hello, world""" 会解析为 said "hello, world"。引用字段也可以跨越物理行；其中的换行保留在同一个单元格中，不会意外产生新记录。记录分隔符支持 CRLF、LF 和 CR。

导出扁平 JSON 对象数组

[{"name":"Ada","code":7},{"name":"Lin","active":true}] 会按首次出现的属性顺序生成表头。某行缺少的属性会写成空白字段。标量值会写为文本；JSON 数字按原始数字文本保留，包括大整数的每一位。

支持的数据、校验规则和限制

CSV 转 JSON 时，分隔符必须明确选择逗号或制表符。解析器支持带引号字段、双引号转义、引用字段内的分隔符以及字段内换行，并支持 CRLF、LF 和 CR 作为记录分隔符。启用表头时，表头必须唯一且非空，每条记录的字段数必须一致。关闭表头后，每条记录会转换为数组。工具不会猜测单元格的数据类型。

JSON 转 CSV 仅接受顶层的扁平对象数组。嵌套数组或对象不受支持，遇到时会明确报错，不会静默展开或丢弃数据。空属性名和重复 JSON 对象属性名会被拒绝，因为它们无法形成可靠的 CSV 表头。属性按 JSON 源文本中首次出现的顺序合并；缺失属性会写为空白字段。JSON 字符串会解码为文本，布尔值和 null 分别写为 true、false 和 null。数字词法片段会从 JSON 源文本直接保留，避免 JavaScript 浮点数舍入大整数。

转换前会检查资源上限：原始输入最多 250,000 个字符；CSV 记录总数最多 10,000 条，其中包含表头；每条记录最多 256 列；全部单元格合计最多 20,000 个。JSON 嵌套最多 100 层，序列化输出最多 500,000 个字符。达到限制时会清除旧输出并显示错误。限制旨在约束浏览器工作量，并不保证所有设备都能瞬间处理最大输入。

输出是普通 CSV 文本，不会执行电子表格专用的安全改写。CSV 引号可以保留字段边界，但不能让类似公式的内容在电子表格软件中自动变得安全。某些电子表格可能会将以公式标记开头的内容当作指令。打开来自不可信来源的数据前请先检查；本工具不会擅自改写单元格，也不会声称完成了公式净化。

所有转换均由页面中的本地 JavaScript 完成。CSV 或 JSON 输入不会上传、发送到 API、写入浏览器存储或加入最近工具记录。工具不提供文件上传。点击清除、离开页面或通过浏览器历史返回时，输入、输出和选项都会清理。

CSV / TSV 转换器常见问题

工具会自动判断分隔符是逗号还是制表符吗？

不会。CSV 请选择逗号，TSV 请选择制表符。输入和输出都使用当前选择的分隔符，避免自动猜测导致转换结果不确定。

CSV 中的数字会转换成 JSON 数字吗？

不会。CSV 单元格始终作为字符串，因此 007、true 和日期样式文本都会原样作为文本保留。JSON 转 CSV 时，标量也会写为单元格文本，并保留数字的原始源文本。

嵌套对象或数组可以转成 CSV 吗？

不可以。JSON 转 CSV 只接受顶层扁平对象数组。遇到嵌套数组或对象会明确报错，不会静默展开、合并或丢弃。

输出的 CSV 可以安全地直接用电子表格打开吗？

这只是普通 CSV，并不是公式净化器。电子表格软件可能会解释类似公式的单元格内容。打开不可信数据前请检查，不能把 CSV 引号当成安全处理。

我的输入会上传或保存吗？

不会。转换在浏览器本地进行。页面不会把数据发送到服务器或第三方 API，不会将内容保存到浏览器存储或最近记录，并会在离开页面时清除临时输入和输出。
