    在浏览器本地拆分 PDF 页面

    输入以逗号分隔的页码或连续范围，每一项会按输入顺序生成一个 PDF。例如 1-3, 5, 8-10 会生成分别包含第 1–3 页、第 5 页和第 8–10 页的 3 个文件。PDF 库和 Worker 由本站提供；文档字节只在本地处理，不会发送到服务器、第三方 API 或 CDN。

    如何拆分 PDF

    1. 选择一个 PDF。文件会在本地检查。暂不支持受密码保护或超过公开大小、页数限制的文档。
    2. 输入页码范围。用逗号分隔单页或连续范围。范围 2-5 会放在同一个输出文件中；2-5, 8 会生成两个文件。同一页不能重复选择。
    3. 拆分并下载。点击“拆分 PDF”，然后分别下载生成的文件。输出文件名根据所选页码生成，不会使用源文件名。

    页码范围示例

    分别提取章节

    输入 1-12, 13-24 会生成两个 PDF，分别包含两个章节范围；输出顺序与范围顺序一致。

    提取指定页面

    输入 2, 7, 10-12 会分别生成第 2 页、第 7 页的单页文件，以及包含第 10–12 页的文件。

    支持的文件与限制

    仅支持一个可读取、未加密且不超过 25 MiB 的 PDF，最多 500 页。最多输入 20 组页码范围；所有输出页数合计最多 500 页，输出文件总大小不超过 60 MiB，处理会在 45 秒后停止。无效、重叠或超出文档页数的范围会在本地拒绝。

    每个输出都是仅包含所选页面的新 PDF。页面提取不保证保留交互式表单、书签、附件、文档元数据或数字签名；重写后原有数字签名将失效。请检查输出并保留原始文档。

    文件会临时读入浏览器内存，并通过同源 Worker 处理；不会上传、写入浏览器存储或保存到最近使用记录。离开页面或通过浏览器历史返回时，所选文件和下载链接会清除。

    PDF 拆分常见问题

    PDF 会上传吗？

    不会。文件读取和页面提取都在浏览器及其同源 Worker 中执行。PDF 字节不会发送到服务器、第三方 API 或 CDN，也不会保存到浏览器存储或最近使用记录。

    逗号分隔的范围如何工作？

    每个逗号分隔的项目会生成一个输出文件。例如 1-3, 5, 8-10 会生成 3 个 PDF。输出顺序与输入范围顺序一致，范围不能重叠。

    可以只提取一页吗？

    可以，输入单个页码，例如 7，即可生成名为 page-7.pdf 的单页文件。

    可以拆分受密码保护的 PDF 吗？

    不可以。本工具不支持受密码保护的 PDF；请勿向本工具输入或分享文档密码。
