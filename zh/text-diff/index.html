此工具会对齐相同的行，并在双栏结果中标记删除和新增的行。适合比较配置文件、日志、代码片段、数据列表和修改前后的文案。全部比较过程都在当前浏览器中完成。

如何比较两段文本

  1. 粘贴两个版本把较早的文本放在左侧，把修改后的文本放在右侧。
  2. 选择比较规则可以忽略连续空白、行首行尾空格、字母大小写，或同时启用两个选项。
  3. 检查每个差异区块左侧高亮删除行，右侧高亮新增行。使用导航按钮在分开的差异区域之间移动。
  4. 复制纯文本差异复制结果会用两个空格表示未改变行、减号表示删除行、加号表示新增行。

常见比较场景

检查配置变更

在应用更新前比较两份环境模板、服务器配置或部署清单。复制和分享结果前，仍应先删除其中的密钥和敏感值。

比较日志或结果列表

查看两次命令输出之间增加或消失的行。如果缩进没有实际意义，可以启用忽略空白。

审阅修改后的文案

比较文档或产品文案的两个版本，在不把草稿发送到远程服务的情况下逐项查看修改区域。

比较规则与限制

  • 算法比较完整的行，不会在单行内部继续高亮具体单词或字符。
  • 忽略空白时，每一行会先去除两端空白，并把连续空白视为一个空格进行匹配；结果仍显示原始行。
  • 忽略大小写使用 Unicode 小写转换，适合一般文本匹配，但不等同于特定语言的专业排序规则。
  • 存在重复相同行时可能有多种有效对齐方式，本工具会确定性地选择其中一种最长公共子序列对齐。
  • 每个输入限制为 200,000 个字符；两侧合计最多 3,000 行，超过安全行组合计算量的比较会被拒绝。文本不会写入浏览器存储、浏览器历史或最近工具列表。

文本差异常见问题

工具会上传两段文本吗？

不会。比较由当前浏览器中的 JavaScript 完成，不会发送包含粘贴内容的请求。

什么是差异区块？

它是一组连续的删除行或新增行。遇到未改变的行后，当前区块结束，导航会移动到下一个分开的差异区域。

可以比较源代码吗？

可以，但只会将其视为纯文本。工具不会解析编程语言语法、自动忽略注释或理解变量重命名。

为什么修改一行会显示为删除一行再新增一行？

逐行差异会把替换表示为删除旧行并新增新行，使复制后的结果保持清晰且容易在其他工具中使用。
