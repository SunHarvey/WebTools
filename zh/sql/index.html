在本地格式化 SQL，不执行查询

这个浏览器 SQL 格式化工具会整理较长的语句，也可以压缩空白，让 SQL 更易阅读或更紧凑。它会识别常见子句、运算符、括号、带引号的值、带引号的标识符和注释，因此关键字大小写与换行不会改写字符串或注释内部的文本。选择 PostgreSQL、MySQL 或 SQLite，可应用常见引用和注释形式的词法规则。所有处理都在浏览器本地完成；工具不会连接数据库、执行语句，也不会上传查询内容。

如何使用 SQL 格式化工具

  1. 选择处理方式和方言。选择“格式化”以按子句换行并缩进，或选择“压缩空白”以缩短排版。根据 SQL 选择 PostgreSQL、MySQL 或 SQLite，以正确处理常见的引用和注释形式。
  2. 设置关键字大小写和缩进。识别到的未引用 SQL 关键字可以转换为大写、小写，也可以保持原样。缩进支持 2 个或 4 个空格。带引号的标识符、字符串和注释保留原文。
  3. 粘贴、处理、检查并复制。可先载入示例，再运行处理并检查结果。此工具不会校验数据库语法或执行 SQL。清除页面或离开页面即可擦除内存中的临时内容。

SQL 格式化与压缩示例

按子句展开查询

select id,name from users where active=true order by id 会在 FROM、WHERE 和 ORDER BY 前换行，并将逗号分隔的项目整理到易读的行中。转换关键字大小写时，不会更改带引号的值。

压缩空白但不删除注释

压缩 SELECT a, b FROM t -- keep this note 会去掉标点周围多余的空格并收紧排版，但会保留注释及其必要的换行。块注释和数据库提示也会保留，不会被删除。

识别方言常见引用方式

PostgreSQL 美元引用字符串、MySQL 反引号和井号注释、SQLite 方括号标识符都会作为完整词法内容保留。遇到这些写法时请选择对应方言。工具并不声称理解所有厂商扩展或完整 SQL 语法。

支持范围与资源限制

本工具只进行识别词法单元的空白格式化，不会建立数据库语法树，不会验证查询是否合法、检查表结构或函数名、改写查询逻辑，也不会执行语句。它支持常见子句、标点、比较与算术运算符、单引号和双引号内容、常见引用标识符、行注释和块注释，以及部分方言引用形式，例如 PostgreSQL 美元字符串、MySQL 反引号和井号注释、SQLite 方括号标识符。PostgreSQL 嵌套块注释会按嵌套规则识别；MySQL 的双连字符只有在后面跟空白时才按行注释处理。此工具无法配置 SQL 模式或会话级字符串设置，包括 MySQL ANSI_QUOTES、NO_BACKSLASH_ESCAPES 和 PostgreSQL standard_conforming_strings；依赖其他设置的语句可能会被不同地识别。较少见的过程式语法、厂商扩展以及词法完整但语法错误的语句，排版结果可能不理想。请在其他环境执行前自行检查生成文本。

格式化会规范空白，并可能将子句或逗号分隔项目换到不同的行；带引号的值、带引号的标识符和注释内部的词元不会改写。关键字大小写选项只作用于识别到的未引用单词；如果未引用标识符恰好与保留关键字同名，也可能被调整大小写。压缩模式仍会保留注释和带引号的内容，因为注释可能包含优化器提示或其他有意义的指令。压缩模式会保留每个左括号前原有的空格；在某些方言或 SQL 模式下，这些空格可能影响函数名的解析。

原始输入最多 250,000 个字符，最多处理 50,000 个词法单元，括号嵌套最多 100 层，输出最多 500,000 个字符。这些独立限制用于约束浏览器工作量和输出大小，不代表任何设备都能瞬间处理最大输入。输入不会写入 localStorage、sessionStorage、Cookie、服务器日志或最近工具记录。离开页面以及从浏览器历史恢复页面时，临时输入和输出都会清除。

此页面是文本格式化器，不是安全的 SQL 执行环境。不要在这里运行数据库命令，也不要把格式化结果当作权限审查或查询安全检查。除非你主动复制，SQL 会一直留在当前页面。

SQL 格式化工具常见问题

这个工具会执行或校验 SQL 吗？

不会。它只通过识别词法内容来调整空白和已识别关键字的大小写，不会连接数据库、执行语句、校验表结构，也不能保证 SQL 语法有效。

支持哪些 SQL 方言？

可选择 PostgreSQL、MySQL 或 SQLite，以处理常见的引用与注释词法差异。这不是完整的厂商语法支持；较少见的扩展和过程式 SQL 可能无法理想排版。

压缩时会删除注释吗？

不会。行注释和块注释都会保留，包括优化器提示；行注释后的换行也会保留，以免后续 SQL 被并入注释。

我的 SQL 会被上传或保存吗？

不会。格式化和压缩都在浏览器本地运行，不会把 SQL 发送到服务器或第三方 API，不会保存到浏览器存储或最近工具记录，并会在离开页面时清除临时值。
