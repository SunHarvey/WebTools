隐私与本地处理

工具输入在您的浏览器本地处理，不会上传到 UtilCover 服务器。

本地处理

提交给工具的文本和文件由设备上的 JavaScript 处理。UtilCover 没有工具处理 API。关闭或刷新页面会清除内存中的工具数据；启用收藏和最近使用后，这些偏好只保存在浏览器 localStorage 中，直到您主动清除。

网络请求

浏览器会请求本站的 HTML、CSS、JavaScript、图标和本地托管的二维码库。UtilCover 当前不使用分析、跟踪像素、广告、第三方字体或第三方 CDN。工具输入不会包含在这些请求中。

边界

浏览器、扩展、网络服务商或被修改的网站副本可能有不同表现。如您的威胁模型要求更高，请使用官方 HTTPS 网站并检查网络活动。
