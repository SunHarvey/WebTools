在本地压缩、缩放和转换图片

本页一次处理一张 PNG、JPEG 或 WebP 图片，可缩小像素尺寸、转换为另一种受支持的格式，也可以调整 JPEG 与 WebP 的输出质量。处理结果会作为新文件下载，不会覆盖原图；图片数据也不会发送到服务器。

图片压缩与尺寸调整方法

  1. 选择一张受支持的图片。文件必须是 PNG、JPEG 或 WebP，大小不超过 16 MiB，像素总量不超过 12 MP。页面会先检查文件头和尺寸，再进行解码。
  2. 设置输出参数。宽高可填写 1–8192 像素。需要保持画面比例时勾选“保持宽高比”；保留“不放大图片”可以避免无意上采样。输出格式可选 PNG、JPEG 或 WebP。
  3. 处理并核对结果。输出 JPEG 或 WebP 时可调整质量，再对照预览、尺寸和文件大小。PNG 采用无损编码，质量滑块不会影响其输出。确认适合实际用途后再下载。

适合处理的图片任务

缩小网页照片

相机照片往往远大于网页中的展示区域。填写合适宽度并保持比例，再导出为 JPEG 或 WebP。相比只降低质量，先减少多余像素通常更符合网页使用需求。

转换截图格式

PNG 截图可以转换为 WebP 或 JPEG，前提是接收图片的平台支持目标格式。带透明背景或细小界面文字时，PNG 往往更合适；以照片为主时可以比较 JPEG 与 WebP 的效果。

制作固定范围的配图

头像、文章缩略图或邮件附件通常有明确尺寸要求。保持比例后，图片会缩放到目标宽高范围内，不会被拉伸。这里不提供裁剪、补边或自动改变构图功能。

格式、尺寸与处理限制

  • 每次只能选择一张 PNG、JPEG 或 WebP 图片；文件上限为 16 MiB，解码后的像素总量上限为 12 MP，不支持批量处理。
  • 输出依赖浏览器 Canvas 编码，只能生成 PNG、JPEG 或 WebP。不接受 SVG、动态 GIF、AVIF 或 HEIC，也无法保留动画。
  • 宽度和高度范围为 1–8192 像素，输出画布同时不能超过 12 MP。不同浏览器的编码器可能让最终文件大小和画面细节略有差异。
  • 格式转换无法找回已经丢失的细节。放大只会增加像素数量，不会恢复纹理；反复保存有损格式还可能累积压缩痕迹。
  • Canvas 导出的新文件不会复制 EXIF 等图片元数据。删除或归档原图前，请先检查方向以及工作流程中是否仍需要这些信息。

常见问题

PNG、JPEG 和 WebP 应该怎么选？

没有透明背景的照片通常适合 JPEG；需要无损细节或透明背景的界面素材可选 PNG；目标平台支持 WebP 时，也可以导出后比较实际效果。最终应以图片将要使用的平台为准。

为什么转换后文件反而更大？

文件大小由像素尺寸、画面复杂度、格式和质量共同决定。把简单的 PNG 图形转成高质量 JPEG，或者再次处理已经优化过的图片，都不保证文件一定变小。

能一次处理多张图片吗？

不能。本页只处理单张图片并生成一个结果，没有队列、压缩包下载或批量命名功能。

选择的图片会上传吗？

不会。文件检查、解码、缩放和 Canvas 导出都在当前设备完成。建议保留原图，直到打开下载结果并确认尺寸、透明背景和清晰度都符合要求。
