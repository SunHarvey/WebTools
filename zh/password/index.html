使用浏览器安全接口生成随机密码

本工具通过当前设备的 Web Crypto 接口生成密码，可自行设置长度、数量和允许出现的字符类型。结果不会发送给 UtilCover。不过，点击复制后密码会进入系统剪贴板，仍需像其他账户凭据一样谨慎保存。

安全随机密码生成方法

  1. 设置长度和数量。每个密码可设为 1–128 位，一次可生成 1–100 个。重要账户应优先使用符合网站规则的较长独立密码。
  2. 选择允许的字符类型。根据接收网站的要求启用大写字母、小写字母、数字和特殊字符。密码长度至少要等于已选类型数量，因为程序会确保每种已启用字符类型至少出现一次。
  3. 生成后妥善保存。只复制需要的结果，并直接存入可信的密码管理器。不同账户使用不同密码；如果发现密码可能泄露，应立即替换。

适合的使用场景

注册新账户

先确认网站允许哪些字符，再生成一条未在其他地方使用的长密码。不要在旧密码后面换数字，也不要围绕网站名称制作容易猜到的固定规律，生成后可交给密码管理器保存。

设置 Wi-Fi 密码

生成路由器和连接设备都能接受的随机内容。需要从纸张手动输入时，可以排除 1、I、0、O 等易混淆字符，减少看错和输错的情况。

准备多条独立凭据

配置测试账户或多台设备时，可以增加生成数量。每条结果都会独立生成，不应把整组密码理解为有顺序的编号，也不应让多个真实用户共用同一条。

生成范围与安全边界

  • 长度范围为 1–128，数量范围为 1–100。界面允许的短密码不代表适合保护账户，目标网站也可能有更严格的最短长度和字符规定。
  • 随机索引来自 crypto.getRandomValues。程序使用拒绝采样，把 32 位随机值映射到字符集合时避免取模偏差，最后的字符顺序也使用同一安全随机源打乱。
  • 每种已启用字符类型会先取一个字符，其余位置再从合并后的字符集合抽取。开启排除易混淆字符后，会在生成前去掉 0oO1IiLl。
  • 页面显示的强度只是根据长度和字符种类计算的本地提示，不是破解时间预测，也不构成安全保证。密码复用、钓鱼、设备状态和保存方式同样重要。
  • 这里不是密码库，不会同步账户、查询泄露数据库或检查网站规则。如果浏览器不支持 Web Crypto，程序会停止，不会降级使用 Math.random。

常见问题

随机密码是怎样生成的？

浏览器通过 Web Crypto 提供 32 位随机值。程序使用拒绝采样选择字符，确保每种已启用字符类型都出现，再用安全随机源打乱最终顺序。

排除易混淆字符会影响安全吗？

可选字符会略微减少，换来更方便的人工辨认。长度和独立使用仍然重要。如果始终通过复制粘贴，而且目标系统接受全部字符，可以关闭此选项。

显示“强”就一定安全吗？

不一定。强度标签只是针对当前文本的简单提示，无法判断密码是否被复用、设备是否受控、账户找回流程是否薄弱，也不知道凭据如何保存。

生成的密码会上传或保存吗？

不会。密码只在浏览器中生成，页面没有账户和存储功能。复制后内容会进入设备剪贴板，其他软件或剪贴板历史仍可能保留它。

需要按固定周期修改密码吗？

密码泄露、重复使用、被不当分享或发生明确安全事件时应立即更换。机械地周期轮换容易形成可预测规律；使用独立随机密码并妥善保存通常更有意义。
