文本整理指南

边统计，边整理粘贴进来的文本

遇到表单字数限制、批量名单、商品编号或中英混排稿件时，可以先在这里核对字符、单词、汉字、行数与段落。所有统计会随输入更新；整理按钮直接处理当前文本，不会另开结果框，也不会把内容上传到服务器。

三步完成统计与清理

  1. 输入原文。粘贴或键入内容，先观察字符、不含空白字符、单词、汉字、行和段落六项数字。
  2. 按需要整理。可以清理每行首尾空白、删除空白行或重复行、重新排序，也可以转换英文大小写。多个操作会按点击顺序执行。
  3. 复核后复制。检查文本框里的改写结果及更新后的统计，再复制到目标位置。工具没有撤销记录，重要原文应另行保留。

适合哪些实际任务

整理编号或关键词清单

把每个编号放在单独一行，先删空白行，再去重和排序。例如 item2 会按数字顺序排在 item10 前。去重只认完全相同的整行，区分大小写，并保留首次出现的那一行。

核对中英混排字段

例如“版本 2 🚀 发布”同时包含汉字、数字、空格和表情。字符项按 Unicode 码点统计；“不含空格”实际上会把空格、制表符和换行等空白字符全部排除，而不只是普通空格。

清理从表格复制的文本

逐行去掉两端缩进，删除空行，再转换英文大小写，适合粘贴到后台录入框。每次转换都会直接改写当前文本框，并立即用新内容重新统计，请先确认操作顺序。

统计口径与使用限制

字符数采用 Unicode 码点，而不是肉眼看到的“字形簇”。由多个码点组合出的表情、带组合音标的字母，可能显示为一个符号却计为多个字符。单词项先匹配 Unicode 字母与数字组成的词元：完全由汉字组成的词元不计入单词，其他包含 Unicode 字母或数字的词元会计入。Han 脚本字符会逐字另计，标点和符号本身不算单词。

换行按 CRLF 或 LF 拆分；非空且没有换行的内容算一行，空文本为零行。文本首尾会先用于判断是否为空，段落则按空白行分块，所以连续空白行仍是同一个分隔位置。删除空白行也会删除只含空格或制表符的行。去重比较整行原文，必须完全相同、区分大小写，并留下首次出现项。排序调用 localeCompare，参数为 numeric: true、sensitivity: base，因此数字会按数值感知排序，不同浏览器语言环境仍可能影响先后。

大写、小写和标题格式都直接改写文本框。标题格式只是简化且依赖语言环境的规则：先将全文转成小写，再把开头或非字母数字之后的字母转成大写。它不理解人名、缩写词和中文排版规范，也不能替代编辑审校。

常见问题

字符数能直接当作数据库字节数吗？

不能一概而论。这里数的是 Unicode 码点；UTF-8 中一个码点可能占多个字节，有些系统还按 UTF-16 单元或可见字形计算。提交前应查看目标系统的字段规则。

为什么中文没有被算成普通“单词”？

工具没有中文分词词典。完全由汉字组成的连续词元不会增加单词项，而是把每个汉字计入“中文字符”，这样不会把整句中文误报成一个英文式单词。

“删除重复行”会合并大小写不同的内容吗？

不会。比较是区分大小写的精确匹配。如果确实想合并 ABC 与 abc，可以先统一大小写，再执行去重，但原来的大小写信息也会随之丢失。

怎样避免误操作丢失原文？

本页没有历史记录或撤销按钮，清理和大小写转换又会直接覆盖文本框。因此应先在原应用保留副本，分步操作并在每一步后检查结果。
