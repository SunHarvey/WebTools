Compress, resize and convert an image locally

This browser image tool handles one PNG, JPEG or WebP file at a time. Use it to reduce pixel dimensions, choose a different supported output format, or adjust JPEG and WebP quality before downloading a new copy. The original file is not overwritten, and its bytes are not sent to a server.

How to resize or compress an image

  1. Choose one supported image. Select a PNG, JPEG or WebP file no larger than 16 MiB and 12 megapixels. The page checks the file header and dimensions before decoding it.
  2. Set the output. Enter width and height up to 8192 pixels, keep the aspect ratio when proportions matter, and leave “Do not enlarge” selected to avoid accidental upscaling. Choose PNG, JPEG or WebP as the result format.
  3. Compress, compare and download. For JPEG or WebP, adjust quality and inspect the reported output size and preview. PNG output ignores the quality slider because the browser encodes it losslessly. Download only after the result suits its destination.

Common image tasks

Shrink a photo for a web page

A camera photo may be far wider than the space where it will appear. Set a practical width, keep the aspect ratio and export JPEG or WebP. Reducing dimensions often removes more unnecessary data than changing quality alone.

Convert a screenshot

Choose a PNG screenshot and export WebP or JPEG when the receiving system accepts those formats and a smaller photographic output is useful. Keep PNG for sharp interface text or transparency when file size is not the only concern.

Create a fixed-size asset

Set a target box for a profile image, article thumbnail or email attachment. With aspect ratio enabled, the image fits inside the requested width and height without stretching; this tool does not crop, pad or change the composition.

Supported formats and limits

  • Input is limited to one PNG, JPEG or WebP image, with a maximum file size of 16 MiB and a maximum decoded area of 12 megapixels. Batch processing is not available.
  • Output uses the browser Canvas encoder and is limited to PNG, JPEG or WebP. SVG, animated GIF, AVIF and HEIC are not accepted, and animation cannot be preserved.
  • Width and height are limited to 1–8192 pixels, while the output canvas must also stay within the 12 MP pixel ceiling. Browser support can affect the exact encoded file size and visual result.
  • Conversion does not restore detail lost in a previously compressed image. Upscaling creates more pixels but cannot recover missing texture, and repeated lossy saves can introduce visible artifacts.
  • Image metadata such as EXIF fields is not copied into the Canvas export. Check orientation and required metadata before deleting or archiving the original file.

Image compressor FAQ

Which format should I choose?

JPEG usually suits photographs without transparency, PNG suits lossless graphics and transparent interface assets, and WebP can work for either when the destination supports it. Test the downloaded file in the actual app or site that will use it.

Why can a converted file be larger?

File size depends on dimensions, image detail, output format and quality. Converting a simple PNG graphic to a high-quality JPEG, or exporting an already optimized file again, does not guarantee a reduction.

Can I process several images together?

No. The page intentionally handles a single image and produces one result. It has no queue, archive export or batch naming controls.

Are selected images uploaded?

No. File checks, decoding, resizing and Canvas export run on this device. Keep the original until you have opened the downloaded result and confirmed that its dimensions, transparency and quality are acceptable.
