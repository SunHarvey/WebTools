Color conversion and contrast examples

Translate a brand HEX token

Enter #336699 to obtain rgb(51, 102, 153) and hsl(210, 50%, 40%). This is practical when a CSS custom property is stored as HEX but a design discussion refers to HSL adjustments. Converting notation does not change the intended opaque sRGB color.

Normalize out-of-range channels

An RGB input such as 300, 127.6, -20 becomes 255, 128, 0 because each finite channel is clamped to 0–255 and rounded. For HSL, a hue of 390 wraps to 30 by modulo 360, while saturation and lightness are clamped to 0–100 before conversion.

Check body text against a surface

Compare #222222 text with a #FFFFFF background and inspect the ratio against the level needed by the actual typography. Repeat for links, muted text, focus indicators and interactive states rather than assuming one pair represents an entire interface.

Supported input and honest limits

  • HEX accepts exactly 3 or 6 hexadecimal digits with an optional # prefix and no alpha. Values containing four or eight digits are rejected rather than silently discarding transparency.
  • RGB requires finite numeric values. Every channel is clamped to 0–255 and rounded to an integer. HSL hue wraps by modulo 360; saturation and lightness clamp to 0–100. Conversions and displayed HSL values round, so repeated round trips can lose fractional detail.
  • Contrast uses the WCAG relative luminance formula. The thresholds are AA normal 4.5:1, AA large 3:1, AAA normal 7:1 and AAA large 4.5:1.
  • The displayed ratio floors the computed value to two decimal places instead of rounding upward. Pass or fail is evaluated from the unshortened computed ratio, so a displayed boundary should not be reverse-engineered as extra precision.
  • This checker does not assess actual font size, weight, transparency, gradients, images, hover or disabled states. It cannot decide whether text qualifies as large, and a passing pair does not establish that the full page meets every WCAG requirement.

Color and contrast questions

Can I enter HEX with or without a hash sign?

Yes. The leading # is optional, but the remaining value must contain exactly three or six hexadecimal digits. Three-digit values expand by repeating each digit, so #369 becomes #336699.

Why did my RGB or HSL numbers change?

The tool normalizes values to what its output can represent. RGB channels become rounded integers from 0 through 255. HSL hue is wrapped into one turn, while saturation and lightness stay within percentages from 0 through 100.

What counts as large text in the result grid?

The thresholds commonly describe large text as at least 18pt, or at least 14pt when bold. This calculator does not inspect a rendered element, so you must decide which row applies using the real font size and weight.

Why floor the visible contrast ratio?

Flooring avoids displaying a rounded-up value that appears to reach a threshold when the calculated ratio is slightly below it. The compliance booleans use the full ratio, while the two-decimal string is a compact display.
