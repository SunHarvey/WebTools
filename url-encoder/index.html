URL component encoding

Use this tool for a path segment, query value, or other individual component. It applies encodeURIComponent, which escapes reserved separators rather than constructing a complete URL.

Error handling and privacy

Malformed percent escapes are rejected. Your input remains in this browser and is not sent to a server.
