Review text changes without uploading either version

This checker aligns matching lines and marks removed and added lines in a side-by-side result. It is useful for configuration files, logs, copied code, data lists and edited writing. Comparison happens entirely in the current browser.

How to compare two texts

  1. Paste both versionsPut the earlier text on the left and the changed text on the right.
  2. Choose comparison rulesOptionally ignore repeated whitespace and leading or trailing spaces, ignore letter case, or apply both rules.
  3. Review each change blockDeleted lines are highlighted on the left and added lines on the right. Use the navigation buttons to move between groups of changes.
  4. Copy a plain-text diffThe copied result prefixes unchanged lines with two spaces, removed lines with a minus sign and added lines with a plus sign.

Common comparison tasks

Check configuration changes

Compare two environment templates, server configurations or deployment manifests before applying an update. Secrets should still be removed before sharing copied output.

Compare logs or result lists

Find lines that appeared or disappeared between two command outputs. Ignore whitespace when indentation is not meaningful.

Review an edited draft

Compare two versions of documentation or product copy and navigate through each changed section without sending the draft to a remote service.

Comparison rules and limitations

  • The algorithm compares complete lines. It does not highlight individual changed words or characters inside a line.
  • When whitespace is ignored, each line is trimmed and consecutive whitespace is treated as one space for matching; the original line remains visible.
  • Case-insensitive comparison uses Unicode lowercase conversion. It is intended for practical text matching, not locale-specific linguistic collation.
  • Repeated identical lines can have more than one valid alignment. The tool chooses one deterministic longest-common-subsequence alignment.
  • Each input is bounded to 200,000 characters. Both sides may contain at most 3,000 total lines, and comparisons that exceed the safe line-pair work budget are rejected. Text is not stored in browser storage, browser history or the recent-tool list.

Text diff questions

Does this upload either text?

No. This tool does not upload either text. The comparison runs in JavaScript in the current browser and makes no request with the pasted content.

What does a change block mean?

It is one continuous group of removed or added lines. An unchanged line ends the current group, so navigation moves between separated regions.

Can it compare source code?

Yes, as plain text. It does not parse programming-language syntax, ignore comments automatically or understand renamed symbols.

Why does a changed line appear as one deletion and one addition?

Line-based diff represents replacement as the old line being removed and a new line being added. This keeps the copied output portable and unambiguous.
