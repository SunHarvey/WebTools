Test regular expressions without sending your text away
This tool runs JavaScript regular expressions against text in a disposable browser Worker. It highlights matches, lists numbered and named capture groups, and shows the result of a replacement string. Patterns, logs, source snippets and replacement output remain in the current tab and are cleared when the page is left.

Common regex testing tasks

      
Extract structured values
Test a pattern for identifiers, dates, email-like strings or log fields. Capture groups make it easier to confirm which part of each match would be reused later.

      
Validate a migration or search rule
Paste representative configuration, code or content samples before using a pattern in an editor or script. Include non-matching examples so accidental overmatching is visible.

      
Preview a replacement
Check numbered groups such as $1, the whole match token $&, or named groups such as $<name> before changing the original file elsewhere.

    

    
JavaScript regex rules and safety limits
    
      
  • The engine is the browser's JavaScript RegExp implementation. PCRE, .NET, Python and RE2 syntax can differ and are not emulated.
    • 
      
  • The supported flags are g, i, m, s, u and y. Only g continues through multiple matches; y controls sticky anchoring and can be combined with g.
    • 
      
  • Some patterns have catastrophic backtracking. Evaluation therefore runs in a fresh Worker that is terminated after 500 ms instead of blocking the page indefinitely.
    • 
      
  • Input is bounded to 2,000 pattern characters, 200,000 test-text characters and 2,000 replacement characters. At most 1,000 matches and 50 capture groups are accepted, while aggregate match/capture data and replacement output each have a 500,000-character limit.
    • 
      
  • The page highlights up to 200 matches and stops the detail list at 1,000 rows to keep the DOM responsive. The total match count can still include up to 1,000 accepted matches. Empty matches are displayed with a visible marker.
    • 
      
  • No input is written to localStorage, sessionStorage, cookies, browser history or the recent-tool list. Leaving the page clears inputs, results and Worker state.
    • 
    

    
Regex tester questions

      
Does this upload my pattern or text?
No. The page does not upload or send your pattern, test text or replacement to an API. The dedicated Worker is loaded from the same site and processes values inside the browser.

      
Why was my pattern stopped?
A pattern that does not finish within 500 ms is terminated to protect the tab. Simplify nested quantifiers, reduce ambiguous alternatives or test the expression on smaller representative input.

      
Why is only one match shown?
Enable the global g flag when you want JavaScript to continue after the first match. Sticky y matching is different because each match must start exactly at the current index.

      
Is this a validator for email addresses or URLs?
It can test a pattern against examples, but a regex alone is rarely a complete standards validator. Use the parser or validation rules of the system that will consume the value.
