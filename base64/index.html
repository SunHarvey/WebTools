How Base64 works

Base64 represents binary bytes using printable ASCII characters. This tool first encodes text as UTF-8, so emoji and non-Latin scripts round-trip correctly.

Limits and privacy

This focused page handles text. It validates padding and UTF-8 instead of silently returning corrupted output. Processing uses native browser APIs and makes no network request.
